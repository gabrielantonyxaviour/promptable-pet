# UI Template Plan

## Direction

Use the polish of Gabriel's templates, but build a real app as the first screen. The experience should feel like a premium creature cockpit, not a landing page or form.

## Template Inspiration

- Primary inspiration: `creative-tool` / `template-lottiefiles` for playful creation-tool energy.
- Secondary inspiration: `webgl-studio` / `template-lusion` for a rich visual scene and motion.
- Avoid: generic SaaS dashboard, beige wellness journal, plain CRUD tables.

## First Screen

The first viewport should show:

- Large animated pet/habitat region.
- Compact daily input controls.
- Week evolution strip.
- "Why it changed" card.
- Backend/plugin witness panel small enough not to dominate.

## Visual Requirements

- Strong contrast, generous whitespace, premium color palette.
- Pet transformation visible within 5 seconds.
- Stable responsive layout for Devpost screenshots.
- No in-app tutorial copy. The interface should explain itself through controls and state changes.
