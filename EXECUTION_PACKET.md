# Execution Packet

## Project

Promptable Pet

## One-Line Hook

A pet that grows because you slept well.

## User Story

People already track mood, sleep, and habits, but the feedback is usually charts. Promptable Pet turns daily care into a visible companion that remembers, changes, and explains itself.

## MeDo Fit

- Backend storage for persistent pet history.
- Backend functions for state transitions.
- Image generation plugin for pet states.
- LLM plugin for short explanations.
- Optional custom skill for reusable pet-state transitions.

## Demo Script

1. Open app on pet scene.
2. Enter: sleep `8h`, mood `calm`, care action `cooked dinner`.
3. Click update.
4. Pet changes color/posture.
5. Week strip adds today's evolved state.
6. Explanation card says why.
7. Open Build Witness drawer showing backend tables, functions, and plugin use.

## Submission Copy Seed

Promptable Pet is a persistent digital companion built in MeDo. It converts daily mood, sleep, food, and care inputs into a living pet state using backend storage, state-transition logic, and generative media. The result is not a habit tracker with a mascot; the creature is the memory surface.
